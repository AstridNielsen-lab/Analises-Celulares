# Análise Oncológica Celular - Like Look Solutions

Este projeto realiza análises de imagens microscópicas para identificar características oncológicas em células. A solução é intuitiva, fácil de usar e auxilia profissionais e pesquisadores na análise detalhada de células.

## Como Usar

1. **Faça upload da imagem microscópica**:
   - Aceitamos os seguintes formatos de arquivo: PNG, JPG, JPEG.
   - Tamanho máximo permitido: **10MB**.
   - Resolução mínima: **1024x1024 pixels**.
2. **Clique no botão "Analisar Células"** para iniciar a análise.
3. **Aguarde o processamento** e a geração do relatório.
4. **Visualize o relatório detalhado** com os resultados da análise.
